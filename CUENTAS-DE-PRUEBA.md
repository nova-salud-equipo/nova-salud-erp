# Cuentas de prueba

Usuarios de demostración para entrar al panel de Nova Salud. Cada rol ve módulos distintos (ver la tabla de roles en el [README](README.md)).

| Rol | Correo | Contraseña | Qué puede ver |
|---|---|---|---|
| Administrador | admin@novasalud.pe | admin123 | Todos los módulos |
| Cajero | cajero@novasalud.pe | cajero123 | Dashboard, punto de venta, pedidos web e inventario |
| Almacén | almacen@novasalud.pe | almacen123 | Dashboard, inventario, alertas y compras |

## Requisitos
- La API ([nova-salud-api](https://github.com/nova-salud-equipo/nova-salud-api)) debe estar encendida y con estos usuarios cargados en su base de datos.

> Estas cuentas son solo para pruebas y demostraciones. No las uses en un entorno real: cambia las contraseñas o elimina estos usuarios antes de publicar el sistema.
